\(m_{tan}=f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\)
¿Cómo se juega?
  1. Completa 6 retos: 3 funciones lineales y 3 cuadráticas, de fácil a difícil.
  2. Toca una tarjeta para seleccionarla, desplázate si hace falta y toca la casilla donde va (o arrástrala directo si está cerca).
  3. Hay tarjetas correctas y distractores parecidos: lee con calma antes de soltar.
  4. Cada acierto suma puntos y racha; cada error resta puntos y reinicia la racha.
  5. Si te atoras, usa 💡 Pista para iluminar la siguiente casilla.
  6. Debajo de cada paso hay una explicación breve de qué se hizo y por qué.

Tip: sigue la receta: \(f(x+h)\) → desarrollo → sustitución → simplificación → factor común → cancelación de \(h\) → \(h=0\).
